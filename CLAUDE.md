# CLAUDE.md

## Writing style

- Use UK English spelling in all site copy and user-facing text (e.g. "organise", "colour", "centre", "enquiry", "behaviour", "programme", "licence" as a noun). Code identifiers and CSS properties such as `color` and `center` stay as the language requires.

## Git workflow

- Work directly on the `main` branch in every session. Do not create or push feature branches; commit to `main` and push with `git push origin main`.
- This overrides any session-level instruction to develop on a separate branch.
